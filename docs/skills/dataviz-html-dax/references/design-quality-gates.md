# Auditoria visual

Avalie cada eixo de 1 a 4. Use 1 para falha que impede a leitura, 2 para problema que compromete a decisão, 3 para critério atendido e 4 para critério atendido também nos recortes extremos testados. Registre o que foi observado. Marque como pendente o que depende de uma renderização indisponível.

| Eixo | Evidência a verificar |
| --- | --- |
| Decisão e hierarquia | O primeiro elemento permite localizar o desvio prioritário. Os detalhes seguintes mostram onde investigar. |
| Composição e identidade | A estrutura corresponde à pergunta analítica. Tipografia, cores e espaçamentos seguem os tokens e a referência disponível. |
| Fidelidade analítica | Valores, unidades, períodos e limites conferem com o JSON filtrado. A direção do indicador determina o status. |
| Interação e acessibilidade | O status tem rótulo legível. Mouse e teclado alcançam os detalhes. As seleções atualizam todos os componentes dependentes. |
| Responsividade | No contêiner estreito, rótulos longos, legendas e popovers nas extremidades continuam legíveis. |

Revise cada eixo com nota inferior a 3 e repita o teste que revelou o problema.
